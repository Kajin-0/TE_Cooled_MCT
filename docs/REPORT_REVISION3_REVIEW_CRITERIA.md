# Report review and numerical release policy

The user authorizes a corrected **Revision 3 REVIEW DRAFT now**, independently
of whether all physical/numerical qualification gates pass. The existing
15-page Revision 2 PDF and its sources/provenance remain immutable historical
evidence; they are not current corrected-geometry results.

The review draft uses only verified, source-referenced two-ear/nine-pin geometry
and actual solved fields from the corrected216-domain/88-leg solid model.
Failed qualification is prominent on the cover/abstract and verification matrix.
It is a standalone scientific document, not certification or OEM validation.
Machine paths, source identifiers and hashes stay in external provenance.
The current review copy is
`reports/generated/HgCdTe_Engineering_Assessment_Rev3_REVIEW_DRAFT.pdf`.
Each published edition retains its own source, figures, PDF and provenance;
updating the current review copy never rewrites an older edition or Revision 2.

Draft creation requires verified source geometry, actual solved-field mapping,
the three-level cold comparison, honest source/captions, readable typesetting,
reader-text/metadata checks and rendered-page inspection. It does **not** wait
for OEM identification, missing enclosure physics or successful raw flux gates.
Future meaningful verified geometry/scientific checkpoints update technical
tables and the review PDF, rather than producing a new PDF for every log.

A later numerical-release candidate requires **both** original raw criteria on
the **same** production mesh and at least one systematically refined comparator:

| Requirement | Hard acceptance | Preferred margin |
|---|---:|---:|
| Ceramic/attach integrated one-sided raw Fourier-power mismatch | absolute <5% | <4.5% |
| Independent Kovar external-underside raw Fourier heat error | absolute <1% | <0.9% |
| Every one of177 interior electrical current cuts | <0.5% at loaded drive | unchanged |
| Global/stage heat and free thermal residuals | <1 µW | unchanged |
| Free electrical residual | <1 µA | unchanged |
| Nonlinear relative stopping criterion | <1e-9 | unchanged |
| Homogeneous baseline and same-mesh reproducibility | passed | unchanged |

The margins are targets, not alternative gates. Separate passing meshes do not
qualify a combined model. Temperature/voltage mesh sensitivity must be reported;
nonmonotone responses and weak/anisotropic refinement ratios do not justify GCI.
Weak reactions or recovered flux never replace an original raw-gradient gate.
All earlier failed evidence remains failed.

Even a numerical-release candidate is a new standalone revision for user review,
with assumptions and lack of OEM/empirical validation explicit. It does not imply
that VIGO installs the independently selected TEC Microsystems candidate.
No cap/window, carrier, wire-on, gas/radiation or optical-window transport result
is added without separately verified physics. The current0.5 mW optical-like
component is imposed volumetric heat, not a transmitted optical prediction.
